- `Pentagonal_Dual_Crystal_Public_Paper_JA_v1.0.pdf`（6ページ）：主定理・定義・補題・強い帰納法・等価性・接続の漸化式。

## 再実行
展開先で Python 3 標準ライブラリのみ：

```
python verify_v10.py
```

Ver.0.9原本73ハッシュおよび内部3原本128ハッシュを検証し、一時ディレクトリで旧査読コードを再実行。8出力を比較する。非縮約285状態の20,855遷移（1下降20,819、2下降36）および130根の停止条件・深さを別途監査する。生成CSV4表と `final_audit.json` は同じ版の納品値と照合できる。証明の根拠は数学的帰納法と有限証明書、反復回数ではない。検査数には重複し得る対象が含まれ、単純加算はしない。

PDF再生成（任意）：

```
python build_release.py
```

WeasyPrint・日本語フォント環境が必要。PDFのバイト一致は環境依存。数理検証はこれらに依存しない。
